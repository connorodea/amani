# Amani

Amani is the nervous system of your Mac — a single command bar that replaces Spotlight
(Cmd+Space) and does two jobs at once: everything Spotlight already does (launch apps, find
files, quick math), and a unified control plane for every agentic process running on your
machine — start, stop, attach, watch logs, and (eventually) semantically search across all of
it in natural language.

Native, FOSS, MIT-licensed macOS app.
